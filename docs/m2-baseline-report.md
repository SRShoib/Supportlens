This is the domain gap SPEC §7 warns about, made concrete: predictions above are frequently wrong or nonsensical on real tweets (e.g. a wireless-connection tip classified as `check_payment_methods`, a font-kerning complaint as `create_account`) despite the model scoring ~0.999 macro-F1 on Bitext's test split. The baseline learned Bitext's 27 templates very well; it did not learn customer intent in general. This gap is exactly the argument for M3's transformer fine-tune, and for eventually fine-tuning (or at least evaluating) on real support text rather than Bitext alone.
